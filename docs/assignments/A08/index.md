# A8 – Gears

## Objective
* Design a gearbox that can be assembled and disassembled.
* Analyze and size input and output shafts for strength.
* Design journal bearings to support shafts.
* Create a gearbox housing with proper clearance and fastening.
* Use parametric CAD modeling to generate a final design.
* Document calculations, sketches, and lessons learned.

With one half of the housing complete, I made a copy and replaced the holes with pins, so my housing would fit together. With the gearbox complete, it was time to create my assembly. I installed the McMaster-Carr Solidworks plugin and used it to import gears, shafts and bearings. I imported Metal Gear 7880K19, Metal Gear 7880K24, Rotary Shaft 1327K93, Rotary Shaft 1327K113, Acetal Dry-Running Sleeve Bearing 2610T2 and Acetal Dry-Running Sleeve Bearing 2610T6. I determined the rotary shafts based off the diameters of the journal bearings and the gear diameter. With all the components selected, I created my assembly.

## Lessons Learned
I learned a lot from this assignment. My first lesson was installing the McMaster-Carr plugin and learning how to import their parts into assemblies. Also, learning how to navigate McMaster-Carr and learn to find the correct components, and how to determine which ones were the correct fit was another learning curve I experienced. I also learned a lot about gears on this assignment, as before, I have never really worked with gears before. This assignment took me 7 hours to complete.
